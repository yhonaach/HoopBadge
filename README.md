# HoopBadge

Orchestrates real-time data processing on a geo-distributed Engine, leveraging auto-scaling across a robust Platform.

HoopBadge is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/HoopBadge.git`
2. `cd HoopBadge`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure HoopBadge, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
